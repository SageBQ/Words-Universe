# Lexicon 词汇宇宙

将英语词汇呈现为可探索的语义星图。每个单词是一颗星球，同义词与近义词之间以星轨相连；点击星球可查看中文释义、词源拆解、记忆故事及关联词。

## 打开网页

- 在线使用：[GitHub Pages](https://sunbaoaoquan.github.io/Words-Universe/)
- 离线保存：下载仓库中的 [`Lexicon-词汇宇宙-可导入PDF版.html`](Lexicon-词汇宇宙-可导入PDF版.html)，在现代桌面浏览器中打开。
- 仓库根目录的 `index.html` 与上述下载版内容相同，是 GitHub Pages 的首页入口。

## 使用方法

1. 在左侧选择语义星系，或在顶部搜索英文单词、中文释义。
2. 点击星球查看词义、词源说明、记忆故事和同义／近义词；点击关联词可继续探索。
3. 使用“稀疏／标准／密集”控制当前星系绘制的星球数量，使用 `+`、`−` 或拖拽调整视图；“返回宇宙”回到总览。
4. 点击“导入 PDF”选择自己的词书。默认会读取整本 PDF，也可以自行设置起止页；核对识别词条后确认导入。扫描页较多或词书很长时，建议等待进度完成，并保留浏览器标签页。
5. 点击“恢复内置词书”可返回项目自带词汇数据。

## PDF 导入说明

网页优先读取 PDF 文字层；扫描页会尝试使用中英文 OCR。PDF 内容在浏览器本地处理，导入操作不会把整份 PDF 传给本项目服务器。首次使用 OCR 可能需要联网下载识别所需资源，因此下载 HTML 文件不代表 OCR 在完全断网时也可用。超长扫描词书会占用较多浏览器内存并延长处理时间。

不同词书的排版差异很大。表格、多栏、扫描质量较差的页面可能出现漏词、错词或分类不准确；请在预览中核对，再决定是否导入。词源拆解与记忆故事是辅助记忆内容，重要事实请以权威词典或原书为准。请勿未经许可公开上传受版权保护的词书全文。
