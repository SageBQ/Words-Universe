# Lexicon 词汇宇宙

将英语词书转成可探索的语义星图：单词是星球，同义／近义词是星轨。支持内置词书、本地 PDF/OCR 导入、AI 学习建议与本机记忆测试。

## 项目入口

- [打开网页](https://sagebq.github.io/Words-Universe/)
- [下载单文件 HTML](./Lexicon-词汇宇宙-可导入PDF版.html)

学习功能包括错因记录与优先复习、近义词辨析练习、词书出处与词典核验入口、多种学习模式，以及按星系统计的成长星图。学习记录仅在当前浏览器本机保存。

## 使用

1. 打开 `single-dist/index.html`，或发布后的 GitHub Pages 首页。
2. 搜索、点击星球或选择左侧主题查看释义、构词提示、记忆故事与近义星轨。
3. 用“导入 PDF”读取任意词书：默认从起始页读取到最后一页；可自行填结束页。文字层优先，扫描页使用浏览器内 OCR。请在预览中核对词条。
4. 用“AI 学习助手”选择 DeepSeek、通义千问、智谱或自定义 OpenAI 兼容服务。普通情况下只需输入自己的 API 密钥；接口和模型可在高级设置修改。
5. 用“记忆测试”按当前词、星系、今日待复习或手动词条生成题目；没有可用 AI 时会自动使用本地词义题继续复习。
6. 在星图上选择“今日复习”“易混词”“构词线索”“近义网络”“写作替换”或“听音回忆”来切换学习路径。打开词卡可以标记记忆状态和具体错因，系统依次安排 1、3、7、14、30 天复习，并将易错词排在前面。
7. 在词卡中打开“近义词辨析”比较两词的原释义，完成有明确依据的简短辨析题；“成长星图”按星系显示已学、掌握和待复习数量。

## 隐私与 AI 边界

- API 密钥只保存在当前网页内存中，刷新、关闭或重新加载后即清除；不会写入本机存储、URL、导出 HTML 或仓库。
- 学习记录（答题次数、正确率、错词和下次复习时间）只保存在浏览器本机，可从测试窗口清空。
- 构词说明与记忆故事是学习线索，不等同于历史词源原文。词卡提供原释义、PDF 页码（如有）及外部词典核验入口；外部词典链接需要网络。
- 页面不会自动发送 PDF、整本词书或未选中词条。AI 词卡只发送当前词与少量候选词；导入校对仅发送用户勾选的 1–10 个词条。
- 某些服务商会阻止浏览器跨域请求；出现该提示时，请配置自己的 OpenAI 兼容代理。本站不提供密钥中转服务。
- AI 生成的释义、词源提示、记忆故事和主题关系均标注为“需核验”，必须由用户确认后才会应用。

## 开发与验证

```powershell
npm test
npm run build:single
```

单文件输出为 `single-dist/index.html`。项目包含 PDF/OCR、词书分类、AI 请求安全、学习记录和本地/AI 测验的自动测试。
